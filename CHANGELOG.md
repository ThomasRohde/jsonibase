# Changelog

## [0.1.0] - 2026-05-13
### Added
- Initial alpha package for typed JSONL-backed record collections.
- Local SQLite index with FTS5 and bundled Model2Vec embeddings.
- JSON-only CLI for workspace initialization, validation, indexing, search,
  listing, and transactional mutations.
- Public ingestion examples for Python PEPs, CISA KEV, and RFC metadata.
- GitHub Actions CI and PyPI trusted-publishing workflow.
